MYSTICAL GARDEN PLAYTEST @VERSION@

Extract the entire ZIP to a normal local folder and run Mystical Garden.exe.
Keep b0_native_lock.dll beside the EXE. Windows 10 or 11 x64 and a fixed local
NTFS volume with ordinary, nonredirected AppData are required. You do not need
Godot or any development tools.

The title screen shows the playtest version. BUILD_INFO.txt also lists the
exact Git revision and multiplayer protocol. Use the same ZIP for everyone
when testing co-op.

Saves and local diagnostics are under %APPDATA%\@ROOT@.
This release starts a new save set. Earlier playtest and prototype saves are
not imported. Keep each build in a separate folder. An older build uses its
own save set. Never copy newer saves into an older build's directory.

Before changing builds, close the game and back up the entire save directory,
including journals, archives and profiles. Leave the original backup intact.

For a bug report, include the build version, what you were doing, whether you
were solo, host or guest, and the approximate time. If asked, use Settings >
Diagnostics to export a report and review it before sharing. Keep saves, IP
addresses, private messages and any other identifying details out of public
bug reports.
