# Compact party HUD and gate reach — 2026-11-10

The Wilds now show a small upper-left stack for up to three teammates. Each row has a 34-pixel illustrated character bust using the character's skin/hair/cloak choices, a clipped name, health bar and small health total. Fallen teammates show a skull and Fallen label. Reviving restores the portrait and displays the current reduced maximum health. The panel excludes the local player, updates from existing authoritative public player state, removes disconnected players, remains available while spectating, and hides in the Garden or when alone. It captures no mouse input and adds no network fields/messages. Rows are 184 by 44 logical pixels with 5 pixels of separation.

`gate_interaction.gd` provides one 2.75-unit ground-distance rule for the Garden gate and cleared onward gates. Crafting, paid-route selection, prompts, upgrade-card selection, checkpoint deposits, extraction and party readiness use this rule. Readiness has a 0.5-unit hold margin so slight movement while waiting does not immediately clear a vote. The Heart uses its own 1.7-unit interaction range. Gates still require encounter completion, checkpoint eligibility and party consent as before.
