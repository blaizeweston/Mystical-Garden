# Main Menu

Choose one of three character slots and one of three Garden slots. Characters retain their class progression and plant familiarity across Gardens. Character capacity can be expanded independently of world capacity.

- Create Character or Customize opens the character editor.
- Delete Character requires confirmation, protects characters in use and retains a recovery copy; Garden worlds are preserved.
- New Garden starts a world, with replacement confirmation and a backup for an occupied world slot. Continue loads the chosen world with the chosen character.
- Delete Garden confirms removal of world progress and preserves all characters.
- Host supports the host plus three guests. Join by IP uses the selected character and the configured address/UDP port. See ONLINE_COOP.md.
- Settings offers primary/alternate key or mouse bindings, fullscreen, VSync, frame limit, audio levels and an aim indicator. Settings also opens from the in-game pause menu. Apply saves; Cancel discards. Escape remains available for menus.

Mouse position controls attack direction. Hold Space or left mouse (the default Strike bindings) to attack continuously at the weapon's current speed. Menus, focus loss and death stop held attacks. Release Strike after closing a menu before resuming. The floor map shortcut is remappable too. See SETTINGS_AND_MOUSE_COMBAT.md.

Grafting uses its crafting panel at rare Wilds altars, normally every eighth encounter. Upgrade cards appear every third cleared gate; extraction is available every sixth cleared gate. Garden plot expansions are researched through the Knowledge tree. Legacy offshoot/finale interactions remain deferred.

Release validation covers menus, profiles, recovery safeguards, remapping, cursor attacks, co-op and the packaged executable using isolated test saves.
