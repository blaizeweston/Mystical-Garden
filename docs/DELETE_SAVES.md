# Deleting saves

Select a slot in the main menu and choose **Delete Save**. Confirm the named slot with **Delete Save**, or cancel with **Keep Save**. This clears both the Garden and character from that slot. Other slots are unaffected; a recovery copy remains under the selected slot's backups directory. Empty slots and slots in use in another window cannot be deleted. Explicitly deleted legacy saves are not automatically imported again. Deleted slots can immediately start a fresh game.
